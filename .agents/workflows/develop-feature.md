# Develop Feature Workflow

Ao desenvolver uma nova feature neste projeto:

1. Leia a solicitação e analise o código existente.
2. Identifique ambiguidades ou decisões que precisam de confirmação.
3. Apresente um plano curto antes de alterar código.
4. Não altere arquivos até que o plano esteja claro.
5. Antes de implementar exiba o plano e peça autorização.
6. Implemente somente o escopo solicitado.
7. Não introduza novas dependências sem justificar.
8. Não altere a arquitetura do projeto sem aprovação.
9. Execute lint.
10. Execute build.
11. Execute testes relevantes.
12. Liste os arquivos alterados.
14. Não faça commit nem push automaticamente.
